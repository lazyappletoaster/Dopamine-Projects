# GUUYamine

A rootless semi-untethered jailbreak for iOS 15.0 - 17.3.1 (arm64e), iOS 15.0 - 18.7.1, 26.0 - 26.0.1 (A12/A13) and iOS 15.0 - 18.7.1 (arm64).

This is just Dopamine Lite for my coming soon GUUYJB. More details will come up after I release it. GUUYJB is going to be a website where you are going to press a button and it’s going to load Dopamine. In memory. Without sideloading.
