# 3layerJBstack (NOT FINISHED)

A rootless semi-untethered jailbreak for iOS 15.0 - 17.3.1 (arm64e), iOS 15.0 - 18.7.1, 26.0 - 27.0 (tested on iPhone SE 2 with iOS 27.0 Developer Beta 4) (A12/A13) and iOS 15.0 - 18.7.1 (possibly iOS 18.7.10 too, not tested) (arm64).
